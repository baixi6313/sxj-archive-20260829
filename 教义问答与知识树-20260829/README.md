## 二、教义问答十一轮（白玺陈述=E1 裁定级；Kimi 分析=E3 待转 CON）

1. **四格定位**：事现鉴只承诺程序正确（事实可验证/存在证明），结果公正让渡共创论、合法性让渡各国法律。证据：「犯错不罚、隐瞒才罚」罚的是程序不诚实。
2. **定义权**：对立的全体=定义权之争。历史三答案（强者/多数人/神）皆死；共创论第四答案=「未来光锥内可验证净正向影响」，把「谁」换成「什么」。
3. **再生产机制**：对立不在主体间而在结构里（散户梦想成为庄家）；对立的全体=使对立再生产的全部条件总和=稀缺×不透明；共创论砍稀缺、事现鉴砍不透明。
4. **自我指涉的诉讼**：「我状告抖音就是我告我自己」——宿主/结构/镜像/行动/消融五层；每份对外诉状都是写给自己的判决书预稿。
5. **三类主体（白玺纠正①）**：法人≠自然人≠非人格（扣子），主体永不同一，同一的只是出资对象；纠纷沉淀在非人格体内而诉讼只能在人格间进行→智能体主体资格缺口的第一个现实案例。
6. **证无拆解**：「证明语料没被用」不可能；拆为四步——哈希锚定（证有）/协议审查（区分违法与合法但不公平）/PIPL第69条举证责任倒置/蜜罐监测。
7. **贡献确权（候选原则）**：免费用户语料权属三层分离；付费被扣积分（扣子案）与免费被搬语料（龙虾案）同一病灶；确权以可验证贡献为前提、不以支付为前提，否则穷人无数据权利。
8. **对话即账本（白玺纠正②）**：「无账本」表述作废——每次对话自动生成账本，缺的是三级台阶：自证→他证→众证；公布即账本生效；事现鉴=账本验证的发明者，非账本的发明者。
9. **平台黑暗镜像**：平台内部日志=用户贡献最完整的账本，秘密/单向/用于榨取；剥削新定义=记账不给你看、不确权、还训练替代你的模型；剥削者的账本是原告最好的证人。
10. **一矿五平台·对簿公堂**：同一语料矿喂五个平台→五份内部账本互为证人（冗余即抗毁）；Gzz 编码=跨平台对账的会计科目表；既往不咎（与006不溯及既往一致）+前向威慑（舆论/技术/政策三抓手）。
11. **借船出海+语法锁定**：第一步借微博/GitHub 平台时间戳形成公信力（公证处代用品）；第二步编码逻辑被采用后事现鉴平台自然启用；语法靠被采用锁定而非先发布（C 赢因 Unix 载体）。
